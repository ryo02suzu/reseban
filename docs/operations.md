# 運用手順（運営者向け）

## 1. 医院の追加（オンボーディング）

1. 運営コンソール「医院」で医院名と管理者のメールアドレスを入れ、「医院を追加して招待リンクを発行」。
2. 表示された招待リンク（7日間・1回限り）を、電話で本人確認したうえで管理者に渡す。メールでは送らない（リンク自体がログインの鍵になるため）。
3. 管理者が登録したら、次を一緒に設定する。
   - 設定 →「施設基準の届出」：届出済みの施設基準にチェック（地方厚生局の届出受理通知を見ながら）
   - 設定 →「セキュリティ」：2段階認証の必須化（推奨）
   - メンバー：スタッフの招待
4. 最初のチェックは、当月＋過去6ヶ月分のレセ電（RECEIPTS.UKE。社保・国保で別ファイルなら両方）を取り込んでもらう。以後は当月分だけでよい。
5. 返戻・査定の実績があれば、ルール →「実績CSVを取り込む」→「この順でルールを並べ替える」。

## 2. マスターの更新

支払基金の基本マスターは、改定時（令和8年は6月）とその後も随時更新されます。**月に1回、請求前（毎月1〜5日頃）に更新を確認**します。

1. [支払基金 基本マスター](https://www.ssk.or.jp/seikyushiharai/tensuhyo/kihonmasta/index.html) から最新の全件ファイルをダウンロード（ファイル名は変えない）。
   - 歯科診療行為マスター：基本テーブル `h_ALL*.csv`、算定回数限度 `h-6_ALL*.csv`、年齢制限 `h-8_ALL*.csv`、併算定背反 `h-9_ALL*.csv`
   - コメントマスター：コメント関連テーブル `ck_ALL_*.zip`、全件 `c_ALL*.zip`
   - 傷病名マスター `b_*.zip`、修飾語マスター `z_*.zip`、歯式マスター `f_*.csv`
2. 運営コンソール「マスター」→「ファイルを取り込む」で全ファイルをまとめて選ぶ（ZIPのまま可）。
3. 件数が前回と大きく違わないか確認する。
4. 医院は、レポートの「再チェック」で新しいマスターで判定し直せる。

※ 記録条件仕様（レセ電の形式）が改定された場合は、`src/lib/uke/layout.ts` の列位置を新しい仕様書で確認・修正し、テストを更新してからリリースする。

## 3. ルールの追加・変更

- 公式テーブル（回数・併算定・年齢・コメント・施設基準）はマスターから自動で作られるため、マスター更新だけで追従する。
- それ以外の観点（前提検査、病名、独自の組み合わせ）は「共通ルール」で管理する。
  1. 改定通知・疑義解釈を「AIでルール案を作る」に貼り付ける。
  2. 案を開き、原文と照らして条件・根拠・直し方を直してから「採用」（無効の状態で追加される）。
  3. サンプル医院や協力医院のデータで誤検知がないか確認してから有効にする。
- 医院は共通ルールを自院だけ無効にできる。独自ルールは医院の管理者が追加できる。

## 4. アカウントの問題

| 状況 | 対応 |
|---|---|
| スタッフがパスワードを忘れた | 医院の管理者が「メンバー」→「再設定リンク」 |
| 管理者がパスワードを忘れた | 医院に別の管理者がいればその人が発行。いなければ運営者が「管理者を招待」で新しい管理者を作り、旧アカウントは新管理者が停止 |
| 2段階認証の端末をなくした | 上と同じ手順で新しいアカウントを発行（2段階認証の解除は本人確認の抜け道になるため運営者は行わない） |
| 退職者 | 医院の管理者が「メンバー」→「停止」（即時ログアウト） |
| 支払いの停止など | 運営コンソール「医院」→「停止」（データは残る） |

## 5. 障害・事故対応

1. 検知：ヘルスチェック・アラーム・問い合わせ。
2. 影響範囲の確認：操作ログ（運営コンソール「操作ログ」）、アプリログ、CloudTrail。
3. 医療情報の漏えい等のおそれがある場合は、速やかに対象医療機関へ連絡し、個人情報保護法に基づく報告の要否を判断する。
4. 復旧後、原因と再発防止策を記録し、医療機関に報告する。

## 6. 定期作業

| 頻度 | 作業 |
|---|---|
| 毎月 | マスター更新の確認、依存パッケージの更新（`npm audit`） |
| 四半期 | 操作ログの確認（不審なログイン失敗、深夜の大量出力など） |
| 年1回 | 脆弱性診断、バックアップの復旧訓練、従業者教育、規程の見直し |
| 改定時 | 記録条件仕様・マスター・共通ルールの見直し、利用規約の改定と再同意（`TERMS_VERSION` を上げる） |
